# 📢 Lapor Pak Jombang

Aplikasi berbasis web untuk pelaporan masyarakat yang dibangun menggunakan **Flask** dan **MySQL**. Aplikasi ini memungkinkan warga untuk mengirimkan laporan kendala atau aspirasi secara digital.

## 🚀 Fitur Utama
* **Dashboard Admin**: Visualisasi data statistik menggunakan Chart.js.
* **Manajemen Laporan**: Admin dapat melihat list laporan terbaru dan memperbarui status laporan.
* **Sistem Login**: Autentikasi aman bagi admin menggunakan Flask-Login dan Password Hashing.
* **Upload Foto**: Mendukung pengunggahan bukti foto laporan masyarakat.

## 🛠️ Teknologi yang Digunakan
* **Backend**: Python (Flask)
* **Database**: MySQL (SQLAlchemy)
* **Frontend**: HTML5, Bootstrap 5
* **Autentikasi**: Flask-Login & Werkzeug Security
